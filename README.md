# 금시그널 — 금 시세 전망 인사이트

국제 금값, 원·달러 환율, 국내 프리미엄, 시장 온도를 조합해 원화 기준 금 시세 시나리오를 탐색하는 정적 웹 앱입니다.

공개 주소: [금시그널](https://goldsignal.designboard.net/)

개인정보처리방침: [개인정보처리방침](https://goldsignal.designboard.net/privacy.html)

저장소: [softm/goldsignal](https://github.com/softm/goldsignal)

## 로컬 실행

```bash
python3 -m http.server 4173 --directory dist
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 주요 기능

- 7일, 30일, 90일, 1년 전망 기간 선택
- 상승, 기본, 하락 시나리오 비교
- 국제 금값·환율·국내 프리미엄·시장 온도 조절
- 금시세 기본 표시 단위는 1돈(3.75g), 필요할 때 1그램·1트로이온스(31.1034768g)로 전환
- 단위에 맞춰 시세·전망 범위·차트 눈금/툴팁·목표가·공유 문구까지 일괄 환산
- 과거 1g 목표가 기록을 원/g 단위로 유지하면서 새 단위에 맞춰 이전
- 화면 중간에 실제 수집 시세의 기간 변화, 시나리오, 환율 민감도 및 실물 거래비용 인사이트 제공
- 표시 시세는 국제 현물 기준 원화 환산 추정가로 국내 금은방 매매가격과 다를 수 있음
- 목표가를 브라우저 로컬 저장소에 저장
- 선택형 Cloudflare 공통 계정 로그인·회원가입(웹 및 Android 시스템 브라우저 인증)
- Android에서 3시간 주기로 새 시장 데이터를 확인해 전일 등락·국제금/환율 기여도·7일 추세를 요약하는 인사이트 알림
- 라이트/다크 테마와 반응형 레이아웃
- 본문과 내비게이션 영역을 확보하는 하단 접기·펼치기 AdFit 배너
- Gold API와 Frankfurter를 이용한 6시간 주기 시장 데이터 자동 수집
- GitHub Actions 기반 GitHub Pages 자동 배포

## 디자인 시스템

UI는 [Google Stitch의 Gold Signal UI System](https://stitch.withgoogle.com/projects/12537166845152557427?pli=1)을 기준으로 구현했습니다. Newsreader·Manrope 조합, 아이보리 페이퍼 표면, 차콜 모놀리스, 브라스 포인트와 편집형 12열 그리드를 데스크톱·모바일 반응형 화면에 적용했습니다.

## 데이터 자동화

`.github/workflows/pages.yml`은 6시간마다 국제 금값과 USD/KRW 환율을 수집해 `dist/data/market.json`을 갱신하고 GitHub Pages를 다시 배포합니다. API 장애 시 마지막 정상 데이터가 유지됩니다.

수동 실행은 GitHub 저장소의 **Actions → Collect market data and deploy Pages → Run workflow**에서 할 수 있습니다.

## 광고 운영

돌봄한눈의 하단 접기·펼치기 경험을 참고하여 대시보드에 광고 영역 하나를 둡니다. 모바일 320×100과 데스크톱 728×90 중 화면에 맞는 한 단위만 사용합니다. 시세 갱신이나 재펼치기를 광고 재요청과 연결하지 않으며, 접힘 상태는 탭 세션에 보관합니다. 로드 실패 시 광고 공간을 반환합니다.

매체·광고단위 상태, 구현 기준, QA 항목은 [AdFit 적용 계획](docs/adfit-plan.md)에서 관리합니다. **코드 설치, 매체 심사 승인, 실제 광고 송출은 서로 다른 상태입니다.**

## 개인정보

앱은 로그인 없이도 사용할 수 있고 Cloudflare 기반 공통 계정 로그인·회원가입은 선택 사항입니다. 로그인 세션과 목표가 저장은 분리되어 있으며 목표가는 사용자의 브라우저 또는 앱 내부 저장소에 계속 보관되고 공통 계정으로 자동 업로드되지 않습니다. 하단 광고의 Kakao AdFit Web SDK에는 광고용 브라우저·세션 식별값, 페이지 주소 및 기기·브라우저 환경정보를 전송하는 경로가 확인되어 이를 별도로 고지합니다. 운영자가 목표가를 서버에 저장하지 않는다는 사실이 광고 SDK의 데이터 처리까지 없다는 뜻은 아닙니다.

자세한 내용은 [개인정보처리방침](dist/privacy.html), Google Play 선언 검토 내용은 [데이터 보안](store/data-safety.md)과 [제출 답변표](store/play-console-answers.md)에 있습니다. Android WebView의 기존 쿠키 및 제3자 쿠키 차단 설정은 유지합니다. 광고 적용 후 Play Console의 **광고 포함 여부를 ‘예’로 갱신**해야 하며, SDK 데이터 항목은 확인한 근거에 따라 별도로 제출해야 합니다.

## Android

Android 앱은 별도 프로젝트 `softm/goldsignal.android`에서 관리합니다. 온라인 화면은 Cloudflare 공통 계정을 사용하고 OAuth는 WebView가 아닌 시스템 브라우저로 넘긴 뒤 일회용 PKCE 코드만 앱으로 반환합니다. 오프라인 복사본은 계속 사용할 수 있지만 로그인·회원가입은 온라인에서만 동작합니다. 웹 프로젝트의 `dist/`는 Android `web-assets/`에 동기화해 오프라인 화면에도 웹 변경을 반영합니다.

이 앱의 수치는 자동 수집 시장 데이터와 사용자가 조정한 가정을 기반으로 한 시뮬레이션이며 실제 시세나 투자 수익을 보장하지 않습니다.

## 가격 단위·목표가의 데이터 기준

| 표시 단위 | 중량 | 내부 계산 |
| --- | --- | --- |
| 돈(기본) | 1돈 = 3.75g | 원/g × 3.75 |
| 그램 | 1g | 원/g × 1 |
| 트로이온스 | 1트로이온스 = 31.1034768g | 원/g × 31.1034768 |

내부 원/g 계산은 `goldUsdOz / 31.1034768 × usdKrw × (1 + premiumPct/100)`입니다. 단위 변경은 계산의 기초가 되는 국제 금값이나 환율을 변경하지 않습니다.

브라우저 목표가는 원/g로 저장합니다(`goldSignalTargetPerGramV1`). 예전에 `goldSignalTarget` 키에 저장된 원/g 목표가는 첫 실행 때 새 키로 복사하고, 기존 목표가의 경제적 의미를 유지합니다. 표시 단위는 `goldSignalPriceUnitV1`에 저장합니다. 새 방문 시 초기 단위는 **1돈**입니다.

## 맥락형 시세 인사이트

- **시장 이력**: `dist/data/market.json`의 첫 수집 기록과 최신 자료의 날짜·국제 금값·환율·원화 환산 변화를 함께 표시합니다. 투자 가정과 혼동하지 않습니다.
- **시나리오**: 선택한 기간·상승/기본/하락 가정에 따라 현재 표시 단위로 중심 전망, 범위, 변동률을 안내합니다.
- **환율 민감도·매매비용**: 국제 금값 고정 시 환율이 10원 바뀌는 가정의 금 원화 환산가 차이와 실물 거래비용을 안내합니다.

이 앱의 금시세는 Gold API·Frankfurter 기반의 국제 금 현물 원화 환산 추정치이며, 실제 국내 매수·매도가/KRX 체결가가 아닙니다. 영업점마다 부가세, 공임·수수료, 스프레드 등이 다를 수 있습니다.


## Android 금시세 인사이트 알림

Android 앱은 알림 권한이 허용되면 약 3시간 주기로 최신 시장 데이터 존재 여부를 확인합니다. 같은 `generatedAt` 데이터는 다시 알리지 않으며, 22:00~07:59에는 알림을 보내지 않습니다. 새 데이터가 확인되면 1돈 원화 환산가, 전일 대비 금액·등락률, 국제 금값과 원·달러 환율 중 어느 요인의 영향이 컸는지, 7일 흐름과 변동성 해석을 한 알림에 요약합니다. 알림은 시장 정보 요약이며 투자 권유나 가격 보장이 아닙니다.
